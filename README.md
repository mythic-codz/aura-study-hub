# Utkarsh By Trms

Free unlocked Utkarsh batches — video lectures, PDFs, live classes and quizzes, all in one place.

## Tech stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (database, auth-less device identity, edge functions)

## Local development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
